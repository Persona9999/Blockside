# 常駐圓形俥鐘（2026-11-05 更新）

俥鐘直接顯示於 HUD，不再有開啟按鈕、彈窗或關閉按鈕。常駐盤面沿用黃銅外圈與前進／後退色塊；桌面129px、手機直向與低高度橫向106px（2026-11-05 summit：原本 184／152px 縮到 0.7，Tim「俥鐘尺寸大約縮小到0.7」），會避開下方操作鈕。盤上顯示檔位縮寫；指令與航速不另外顯示（下方狀態列本來就有，Tim「旁邊不用顯示前進&航速資訊」），盤下只留 G 後、T 前兩顆（停俥用中央，Tim「按鈕則只保留前(T) 後(G) 且改到俥鐘下方」）。

- 點任一有效外圈檔位放開即下令；拖曳時藍綠指針只是預覽，放開在有效範圍才下令一次。
- 中央停俥鈕可點按停俥，也可直接從中央拖到外圈選檔。按下中央本身不會立即停俥，短點放開才停俥；拖出盤外不會誤觸停俥。
- 拖曳中像虛擬搖桿：拖出圓盤也照指標在盤心的哪個方向選檔，放開就下令（2026-11-05 summit；Tim「讓滑鼠(或手機拖曳) 離開俥鐘範圍時仍然可以運作(參考虛擬搖桿概念 根據方位判定)」）。⛔ 以前盤外放開＝取消。
- 中央非按鈕區與下方空弧是死區（拖曳中也是：拖回盤心、指向正下方都不選）；放開在死區、pointercancel、失去捕獲、視窗失焦、換船或 Esc 均取消預選，不改指令。
- 第二根手指不能搶第一根拖曳；拖曳後的合成點按不會重送指令。
- 圓盤具名原生檔位鈕保留鍵盤操作。方向鍵逐格、Home／End 到兩端，T／G 與可改鍵 W／S（無帆動力船）沿用共同入口；keyup 仍傳給既有輸入清理。
- 沒有額外動力則隱藏；沉船、設定／說明、不允許下令的模式停用。自訂檔位表缺少0不會把其他檔位當停俥。

動力物理、teleSet／teleHand 與帆裝判定不變。較早版本的 popup 截圖與驗收記錄只作歷史；目前驗收見 INLINE_TELEGRAPH_CHECK.md 與 inline-*.png。
