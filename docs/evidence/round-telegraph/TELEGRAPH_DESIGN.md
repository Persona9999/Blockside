# 常駐圓形俥鐘（2026-11-05 更新）

俥鐘直接顯示於 HUD，不再有開啟按鈕、彈窗或關閉按鈕。常駐盤面沿用黃銅外圈與前進／後退色塊；桌面184px、手機直向152px（讀數與快捷鈕排在旁邊）、低高度橫向152px，會避開下方操作鈕。盤上顯示檔位縮寫，下方分開顯示指令與實際航速。

- 點任一有效外圈檔位放開即下令；拖曳時藍綠指針只是預覽，放開在有效範圍才下令一次。
- 中央停俥鈕可點按停俥，也可直接從中央拖到外圈選檔。按下中央本身不會立即停俥，短點放開才停俥；拖出盤外不會誤觸停俥。
- 中央非按鈕區、下方空弧及盤外是死區；放開在死區、pointercancel、失去捕獲、視窗失焦、換船或 Esc 均取消預選，不改指令。
- 第二根手指不能搶第一根拖曳；拖曳後的合成點按不會重送指令。
- 圓盤具名原生檔位鈕保留鍵盤操作。方向鍵逐格、Home／End 到兩端，T／G 與可改鍵 W／S（無帆動力船）沿用共同入口；keyup 仍傳給既有輸入清理。
- 沒有額外動力則隱藏；沉船、設定／說明、不允許下令的模式停用。自訂檔位表缺少0不會把其他檔位當停俥。

動力物理、teleSet／teleHand 與帆裝判定不變。較早版本的 popup 截圖與驗收記錄只作歷史；目前驗收見 INLINE_TELEGRAPH_CHECK.md 與 inline-*.png。
