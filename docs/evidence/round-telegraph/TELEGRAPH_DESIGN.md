# 圓形俥鐘：設計與操作

參考是Steam提供的《Silent Hunter 4: Wolves of the Pacific》原廠手冊，第8頁（PDF索引7）的Navigation Training：圓盤可點選速度、前進在右、後退在左。來源：https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/15200/manuals/manual_english.pdf?t=1680013334 。本批借用其分側選檔概念，未拷貝遊戲圖像；放大操作盤、拖曳預覽／放開下令及中央停俥是本次設計。

原先34×112直條改為112×112黃銅圓盤。小圓盤只讀目前指令、點開288px大圓盤，九個檔位均有具名原生按鈕；右側前進、左側後退、上方停俥。中央及小圓盤下方都有一鍵停俥。中央狀態分開顯示下令檔位與實際航速；停俥只把額外動力設為0，不保證有帆的船立即停止。

操作：

- 點檔位／鍵盤Enter選定，只送一個既有teleSet指令。
- 指針實線表示已下令，藍綠色指針只作拖曳預覽；放開且仍在有效圓弧內才送出。中央死區、下方空弧、拖到盤外、pointercancel、換船都不下令。第二根手指不能搶走第一根的拖曳。
- 既有可改鍵的T／G逐格操作保留。控制器取得焦點時，方向鍵逐格、Home／End到兩端、Esc關閉；鍵盤事件不傳給戰鬥按鍵，keyup仍讓既有操舵與控帆清理收到，避免按住後卡鍵。
- 原先iPhone雙擊防放大會補合成click，因此忽略剛結束或取消拖曳後的合成click；原生鍵盤啟動仍可用。開啟圓盤採冪等行為，不因重複click立即收起。
- 動力受損以紅色外緣小標記提示可達不到的檔位，保留既有指令和動力計算。沒有動力、沉船、設定／說明或不允許戰鬥操作的模式，不可下令；沒有0檔的自訂表也不會把非零檔冒充停俥。

只調整UI，動力、加速度、慣性、帆和自動駕駛規則維持既有teleSet／teleHand機制。
