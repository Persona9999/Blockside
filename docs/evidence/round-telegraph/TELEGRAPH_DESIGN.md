# 常駐圓形俥鐘

俥鐘直接顯示於 HUD，黃銅薄外圈、右前進／左後退色塊。桌面直徑110px，手機直向與高度480px以下90px，約為129／106px的85%。外圈在300px設計座標由24px削至14px，刻度面向外擴張以保留辨識空間，原生檔位按鈕與刻度中心保持對齊。中央停俥鈕30px；盤下保留 G 後、T 前，快捷鈕高度28px不跟著縮小。盤面自動避開下方操作鈕。

- 點按或拖曳外圈選檔；拖曳時藍綠指針為預覽，放開只下令一次。
- 中央短點停俥，也能從中央拖出選檔；按下中央本身不立即下令。
- 拖出盤外仍依指標相對盤心的方向選檔，像虛擬搖桿。中央非按鈕區與下方空弧是死區。
- 死區放開、pointercancel、失去捕獲、視窗失焦、換船或 Esc 取消預選。
- 第二指不能搶拖曳；合成點按不重送指令。
- 具名原生檔位鈕保留鍵盤操作。方向鍵逐格、Home／End 到兩端，T／G、可改鍵W／S（無帆動力船）沿用共同入口；keyup傳給既有輸入清理。
- 無額外動力則隱藏；沉船、設定／說明、不允許下令的模式停用。自訂檔位表沒有0則不提供停俥。

動力物理、teleSet／teleHand與帆裝判定不變。目前版面驗證見 ../mobile-hud/MOBILE_HUD_CHECK.md；round-telegraph下先前的截圖與驗收記錄為當時版本的證據。
