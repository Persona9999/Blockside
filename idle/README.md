# 🦈 方舷放置：鯊魚艦隊的無盡海（Blockside Idle）

Blockside 的海戰核心 × 增量（放置）遊戲的外殼。打開 `idle.html` 就能玩；存檔在瀏覽器（localStorage `bsidle.v1`），跟 Blockside 本體的設定存檔分開。

## 玩法

- **一個海域一場**：我方艦隊（電腦開船、開砲）對那個海域的敵艦。打下來的每一格船殼 ＝ 一格 🧱（貨幣），擊沉、俘獲（降旗）、殉爆另外有賞金。
- **一區 10 個海域**，第 10 個是守將（強度 ×2、賞金 ×5）：加勒比淺灘 → 古代航道 → 西班牙大陸 → 北海風暴 → 幽靈海域 → 風帆巨艦 → 鐵甲時代 → 遠東艦隊 → 大漩渦 → 深淵（循環、越來越強）。
- **打輸（或 3 分多鐘分不出勝負）** ⇒ 退一個海域練功，贏 3 場自動回去挑戰（「自動推進」關掉 ⇒ 停在原地刷）。
- **升級**（格）：砲術、裝填、火藥、船殼、抽水、帆裝、鑑價、賞金、骷髏旗、鯊魚利齒。
- **船塢**：擊敗過的那一型拿到藍圖，就能造；艦隊位置另外買。藍鯊號是打過第 15 海域的禮物。
- **艦隊方針**：擊沉派／穩健派／拆桅派／殺傷派／賭徒 ＝ 核心的砲長（51_captain.js），我方每艘照它瞄。
- **點敵艦咬一口**（或空白鍵）：在水線下挖一個洞 ⇒ 進水；技能 1～4：全艦齊射、鯊魚狂潮、巨齒鯊、緊急搶修。
- **潛回亞特蘭提斯（轉生）**：第 25 海域起可以。帶走三叉戟碎片（累計每顆收入 +10%），買深海科技（轉生也留著）。
- **離線**：關掉、切走的時間照最近幾場的收入速度 × 離線效率（25% 起）補給妳。

## 強度怎麼換成模擬

數字可以一直變大，可是模擬裡的東西都夾在範圍內 ⇒ 戰局永遠是正常的物理：

- 火力比 `atkR` ＝ 我方火力 ÷ 海域強度：敵艦船殼硬度 × atkR^−0.55、我方每發傷害 × atkR^0.55、洞的半徑 × 1.5 × atkR^0.35。
- 船堅比 `defR` 反過來作用在我方船殼與敵方砲彈。
- 放置模式的底：敵艦硬度 ×0.15、進水 ×6、抽水 ×0.4（不然兩艘小船對轟五分鐘還分不出勝負 —— 2026-10-30 量的）。
- 常數都在 `js/10_data.js` 的 `BAL`；調手感只改那一支。

## 檔案

| 檔 | 管什麼 |
|---|---|
| `shell.json` | 外殼設定（`admin.py shell`）：寫到 `../idle.html`、核心 `../index.html`、`opt.q` 預設網址參數、`opt.api` 開外殼 API |
| `idle.css` | 樣式；把核心的主選單、HUD 藏起來 |
| `js/00_base.js` | 小工具：中文大數字（萬、億、兆、京…）、存檔、外殼內的事件 |
| `js/10_data.js` | 數值與內容表：BAL、海域、升級、深海科技、技能、方針、成就 |
| `js/20_econ.js` | 存檔、倍率、海域編成、買東西、轉生、離線、成就 |
| `js/30_battle.js` | 一場一場打：開戰、每艘的設定、收入、降旗、波次、勝負、咬、技能 |
| `js/40_fx.js` | 飄字、船上的標記、訊息列、自動運鏡 |
| `js/50_ui.js` | 介面：資源列、海域卡、面板（艦隊／升級／深海／成就／紀錄）、技能列、彈窗 |
| `js/90_main.js` | 開機、標題、主迴圈、鍵盤、離線、換海圖重新載入 |

核心這一側只加了外殼 API（`src/js/91_shellapi.js`、`src/CORE_API.md` §7）、預設網址參數（`src/js/00_core.js`）、點畫面的掛鉤（`src/js/71_input.js`）；Blockside 自己的頁面跟沒加之前逐位元組相同（兩組無頭對拍）。

## 建置

```bash
python -I src/admin.py build --code          # 核心（index.html）；改了 src/ 才要
python -I src/admin.py shell idle/shell.json  # 套外殼 ⇒ idle.html（改了 idle/ 就重套）
python -I src/admin.py shell idle/shell.json --check   # 比得出 idle.html 舊了沒
```

⛔ 外殼的 js 裡不要有「</」：套頁時會換成「<\/」，正規表示式 `/</g` 就壞了（寫成 `/[<]/g`）。

## 海圖

海域可以帶海圖（`10_data.js` 的 `map`／`site`；Blockside 的 `maps/<名字>`，用 Blocksail 的 `tools/export_chunks.cjs` 匯出）。核心開機時讀 `?map=`，換到別張 ⇒ 存檔、重新載入這一頁、接著打。

## 測

- 內建瀏覽器的窗格藏著的時候 `requestAnimationFrame` 不跑 ⇒ 模擬停住：主控台 `requestAnimationFrame = cb => setTimeout(() => cb(performance.now()), 33)`，再截一張圖踢一下。
- `BSI`（外殼）、`BS_SHELL.core`（核心 API）在主控台都摸得到；`BSI.S.speed = 8` 快轉。
