# 海圖塊格式（TASK-0721）

在岸邊、小島旁開戰用的地形：陸地＋海底（沙底、珊瑚礁、沙洲、礁石）。一個**海域**切成一塊一塊的**海圖塊**，開戰時只載附近幾塊，船隊走到別塊就換中心重載。

Tim 2026-10-19：「可以先定一出一套通用格式（目前構想是1平方公里作為一格地圖 然後海戰時會載入附近9格地圖(所以總共9平方公里) 具體參數細節可以由妳決定(之後可調) 然後整體移動到另一格地圖格時重新載入另一格座標為中心的9格」

## 1. 檔案

```
maps/<海域>/area.js        BSMAP.area({...})                     海域的說明（一個檔）
maps/<海域>/<cx>_<cy>.js   BSMAP.chunk("<海域>", cx, cy, "<base64>")   一塊一檔；全是深海的塊沒有檔
```

- 跟 `index.html` 放在一起（同一個網站、`file://` 也讀得到 —— 用 `<script>` 載，不用 fetch）。
- 海域名稱：小寫英數、底線、連字號。
- 產生：世界地圖工具（`tools/export_chunks.cjs`：照向量的海岸線、等高線＋每座島的種子生成高度與底質）；同一份輸入兩次逐位元組相同。

## 2. 座標

- 海域有一個原點（`lon0`、`lat0`），用當地平面（公尺）：**往東 x、往南 y**。
- 塊 `(cx, cy)` 蓋往東 `[cx·chunk, (cx+1)·chunk]`、往南 `[cy·chunk, (cy+1)·chunk]`。
- 一塊有 `n × n` 個取樣點（`n = chunk ÷ step + 1`），第 `(i, j)` 點在往東 `cx·chunk + i·step`、往南 `cy·chunk + j·step`；**四邊跟隔壁那塊共用**（生成不看框 ⇒ 共用的點逐位元相同）。
- 遊戲的世界座標（公尺；y 朝上、北 ＝ −z）：世界原點（兩隊正中間）＝ 海域裡的**開戰位置**（`sites[k]`）⇒ 世界 `x = 往東 − site.x`、`z = 往南 − site.y`、高度 ＝ 海圖的高度（海面 0）。

## 3. `area.js`

| 欄位 | 意思 |
|---|---|
| `id`、`name` | 海域名稱（檔名用）、顯示的名字 |
| `lon0`、`lat0` | 原點經緯度 |
| `chunk`、`step`、`n` | 一塊幾公尺（預設 1024）、取樣間距（預設 4 m）、一邊幾個取樣點（257） |
| `x`、`y` | 塊號範圍 `[最小, 最大]`（含） |
| `chunks` | `[[cx, cy, 有沒有檔], …]`：0 ＝ 全是深海（不寫檔，讀的時候當 `deep`） |
| `sites` | 開戰位置 `[{ x, y, r, land }]`：往東、往南公尺；半徑 `r` 裡全是 ≥ 10 m 的水；`land` ＝ 離最近的陸地幾公尺 |
| `deep` | 海域外、沒有檔的塊的高度（−150） |
| `mat` | 底質代碼表（下面） |
| `source` | 資料來源 |

## 4. 一塊（`BSC1`，base64）

| 段 | 內容 |
|---|---|
| 檔頭 | `BSC1`、版本 1、cx、cy（zigzag）、n、step（公分） |
| 高度 | 分米（Int16）；照列由北往南、每列由西往東：**平面預測**（左 ＋ 上 − 左上；第一列只看左、第一欄只看上）之後的差，zigzag；連續的 0 合成一個「跑」：記號 t 奇數 ⇒ (t >> 1) ＋ 1 個 0、偶數 ⇒ 差 ＝ zigzag(t >> 1) |
| 底質 | （值, 連續幾個）一對一對，蓋滿 n × n |
| 數字 | 無號變長整數（每 7 位元一個位元組，低位先）；有號的先 zigzag（0, −1, 1, −2 … ⇒ 0, 1, 2, 3 …） |

**底質**（`BED_MAT`）：`DEEP` 0 深海底、`SAND` 1 淺海沙底、`REEF` 2 珊瑚礁、`SHOAL` 3 沙洲、`ROCK` 4 礁石、`BEACH` 10 沙灘、`LAND` 11 陸地、`CLIFF` 12 岩壁。

## 5. 遊戲怎麼用（`src/js/08_seabed.js`、`32_ground.js`、`63_bed_gl.js`）

- 開法：`?map=<海域>[&site=<第幾個開戰位置>]`。沒有 `?map` ⇒ 什麼都不載，戰局跟以前逐位元組相同。
- **載入**（設定檔 `config/game.json` 的 `map`）：焦點（還在打的船的中心）所在那一塊為中心，`ring`（預設 1 ⇒ 3×3）是在用的、外面再預載 `prefetch`（預設 1）圈 ⇒ 5×5；焦點走進別塊 ⇒ 換中心、載新的、丟掉不在範圍裡（也不在任何船旁邊）的。
- **戰局跟載入快慢無關**：每一步模擬之前，每艘船 `margin`（預設 300 m）內有檔的塊都要載好；還沒 ⇒ 這一格畫面先不走模擬。快轉、無頭（`?demo`）⇒ 開戰前整個海域一次載完。
- **查詢**：`bedHgt(x, z)` 高度（雙線性）、`bedMat(x, z)` 底質（最近的點）、`bedGrad(x, z)` 坡度；海域外、深海塊 ⇒ `deep`。
- **擱淺**（`32_ground.js`）：船底 7 點（龍骨線）碰到海底 ⇒ 減速（壓得越深越多、往高處開再多一倍）、壓進 1.2 m 以上沿坡推回去；剛碰上與還在動（> 0.8 m/s）每秒打掉船底 硬度 × 速度² × 1.5 格（珊瑚礁 1、礁石與岩壁 1.5、陸地 0.6、沙灘 0.4、沙 0.25）⇒ 船殼破了照常進水。
- **避開**（`54_helm.js bedAvoid`）：電腦開的船往前看 40／80／130／190 m，船底下面不到 1.5 m ⇒ 往左右 30°、60° … 試第一個夠深的方向。
- **砲彈**打到陸地、海底 ⇒ 停、冒一團煙。
- **畫面**（`63_bed_gl.js`）：每塊一份網格（在用的 8 m 一點、預載那一圈 16 m，四邊垂裙邊蓋接縫），顏色照底質與高度；水下的由海面的折射透出來（畫質「折射：高」；有海圖時水下透出來的東西 1,600 m 內看得到、每公尺吸掉 0.12 —— 沒有海圖照舊 500 m、0.3 ⇒ 淺海、礁、沙洲看得出顏色）；霧比海上淡（0.4 倍）⇒ 幾公里外的島看得到。
- 讀數：`?debug=1` 的 `__game.bed([x, z])`：載了哪幾塊、換過幾次中心、等過幾次、每艘的擱淺讀數、那一點的高度與底質。

## 7. 還沒做

- 遠處的島只畫載到的塊（5×5 以外看不到）；之後加一層粗的遠景。
- 浪打到岸邊的白沫、淺水的浪變陡；鏡頭會鑽進地裡。
- 碎木、落水的人、錨還不看海底（錨照舊的水深算）。
- 擱淺的船不會因為潮水浮起來；沒有潮汐。
